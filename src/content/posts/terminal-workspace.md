终端可以很朴素。几个熟悉的命令、一份清楚的目录结构，就足够支撑许多日常工作。

## 先整理最常用的动作

与其一开始就安装很多插件，不如先记下每天重复最多的三件事：进入项目、运行检查、查看改动。为它们提供稳定的入口，往往比增加一整套复杂配置更有效。

```bash
cd ~/projects/demo_personal_blog
npm run typecheck
npm run build
```

## 让反馈清楚一点

一个好用的工作台，应该让人知道自己在哪里、正在做什么，以及上一步是否成功。终端提示符、Git 状态和简洁的命令输出，都在回答这些问题。

## 留下能复现的说明

把环境版本、安装步骤和常用命令写进 README。下一次换电脑，或者几个月后重新打开项目时，这些记录会让重新开始变得容易。
